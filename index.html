About

I'm Andrew Lukmantara. Drew for short. I build things because I want to see if they work.

Some of them started at hackathons, like CarbonMail at Dragon Hacks 2026. Some started as a notebook, like my first linear regression, and grew into bigger questions, like whether Hong Kong stock announcements predict returns.

I write Python for machine learning and research, TypeScript for web apps, and Swift when a project wants to be a game.
